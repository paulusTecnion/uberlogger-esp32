Getting started

Overview

The Uberlogger control panel lets you configure, monitor and control your logger:

  • Live data: watch all channels live and view CSV log files
  • Files: browse, download or delete log files, unmount or format the SD card
  • Configuration: channels, sample rate and resolution, file options, Wi-Fi and firmware updates
  • Start logging (top right) starts and stops a recording from any page

Note: It is essential to configure the logger and its input channels correctly before starting any measurements to ensure accurate data.

Live data & CSV viewer

The Live data page shows all enabled channels in one chart: voltages on the left axis, temperatures (NTC) on the right axis and the digital inputs as separate lanes below. The values under the chart are the live readings of each channel; they update every second.

  • Time window: choose 1m, 5m, 15m, 1h or All. The browser keeps about 6 hours of history, also when you switch pages or reload.
  • Inspect: hover the chart to read the values at that moment. Click (or click and hold) to freeze the chart and pin that moment. Drag or scroll to zoom, Shift+drag to pan; on a phone use two fingers to zoom.
  • Back to live: after zooming or clicking, the Back to live button (next to Clear) follows the newest data again. Double-clicking the chart does the same.
  • Channels: click a channel name under the chart to hide or show it.

Viewing CSV files

Use Open CSV… on the Live data page, or drop a CSV file anywhere on the page, to view a log file from your computer in the same chart (download it first from the Files page). The file is processed in your browser; nothing is uploaded to the logger. Times in the file are UTC. Gaps in the timestamps are marked with red lines. Very large files need a lot of memory: the viewer warns you before opening a file that may be too large for your device.

Files page

The Files page lists the folders and files on the SD card, with their size and the free space on the card. Click a folder to open it; use the path above the list to go back.

  • Download: click the download icon next to a file to save it on your computer. Open it on the Live data page with Open CSV… to view it.
  • Delete: click the trash icon and confirm. If the file cannot be deleted, a message tells you so.
  • Refresh reloads the list.
  • Unmount (or the eject icon in the top bar) unmounts the SD card so you can remove it safely. To mount it again, take it out and reinsert it.
  • Format… erases all files on the SD card.

Note: unmounting and formatting are only possible while the logger is idle, so not while logging, calibrating or formatting.

Measuring

Channel configuration

The UberLogger can measure temperature, analog voltage, and digital signals. Ensure the correct configuration for accurate results:

  • Enabling channels: You can enable or disable or signal using the enable checkbox. Disabling channels leads to smaller log files. Ideal for long measurements.
  • Custom labels: You can give each label a custom name. The maximum length is 16 characters and cannot contain any space or special characters, except hyphens '-' and underscores '_'.
  • NTCx/AINx selection: Choose between temperature or voltage for each channel using both the hardware DIP-switch and the configuration page.
  • AINx range selection: Adjust the input voltage range (-10V ... +10V or -60V ... +60V) for better resolution and reduced noise. This should also be set using the DIP-switch and the configuration page.

Sampling settings

The UberLogger allows configurable sampling rates and resolutions to capture data accurately. The sample rate affects:

  • Maximum frequency: The higher the sample rate, the higher the frequency the logger can capture.
  • Storage space: Higher sample rates require more space on the SD card.
  • Frequency requirements: The appropriate sampling frequency for your measurements depends on the signal you wish to capture accurately. It is recommended to set the sample rate at least twice the maximum frequency of the signal of interest. For instance, if your signal's highest frequency is 50 Hz, logging at 100 Hz will prevent aliasing (signal distortion due to a too low sample rate). For temperature logging, most applications can achieve satisfactory results with sampling frequencies as low as 1 Hz or 5 Hz. This ensures sufficient data points for precise temperature measurements without significantly increasing data storage requirements.

The resolution can be set to 12-bit or 16-bit. Higher resolutions improve accuracy but may impact performance at high sample rates.

Averaging

For sample frequencies below 1 Hz, you can choose to average the samples over the desired sample frequency or only take one sample at the desired sample rate. For example, if you enable this option with a sample frequency of 1 Sample/minute, the average will be taken over 1 minute of samples using an IIR filter. After 1 minute, the average will be output to the file.

Note: Averaging is performed using a 25 Hz sample rate and an IIR low-pass filter with a -3 dB cut-off frequency at the desired output sample rate.

Measurement mode

The UberLogger supports three measurement modes. The key difference is who controls start and stop: you, or the external digital input.

  • Continuous measurement: Normal manual operation. Start and stop logging from the web interface or with the physical button.
  • External trigger: You still arm logging manually (web/button). After arming, the logger waits for the configured EXT pin to go HIGH before samples are recorded. Note: While waiting for a trigger, the logger is armed but not yet measuring. Live data appears only after the trigger event.
    Logging stops when the EXT pin goes LOW again (or when you press Stop).
  • External control: Start/stop is fully controlled by the EXT pin. Note: In this mode, web Start/Stop and the physical Start/Stop button are disabled by firmware.
    EXT pin HIGH starts logging automatically; EXT pin LOW stops logging.

For both external modes, configure trigger debounce time to filter noisy trigger edges or have delayed measurement starts. Default is 100 ms; adjustable up to 60000 ms. The signal must stay stable for the full debounce time, otherwise the debounce timer restarts.

Calibration

The Calibration section allows you to perform zero-calibration of the analog channels.

Zero calibration ensures that each analog input reads 0 when no signal is present. It is essential for accurate measurements.

You can initiate calibration by pressing the "Start Calibration" button. Ensure that all analog and temperature inputs are all disconnected and all channels are configured as analog inputs both with the DIP switches as well in on the Configuration page before starting calibration, to get accurate results.

Files & time

File options

The File Options section allows you to configure how the UberLogger saves its data.

File Format:

  • CSV: CSV format writes data directly to CSV files, ideal for low sample rates or short measurement durations. CSV files are easily readable in tools like Excel.
  • Raw Data: Raw format records raw data for long measurements, which can be later converted into CSV files using the provided Python or Windows conversion tools. Raw data is more storage efficient for long recordings.

File Name Mode:

  • Sequential: Generates filenames in a sequential order (e.g., `log0`, `log1`, etc.), overwriting existing files with the same name.
  • Timestamp: Generates filenames with a timestamp in the format `YYYYMMDD_Time_FilePrefix.csv`. This avoids overwriting and helps track when files were created.

File name and split size:

  • Prefix: Set your own prefix for a filename. No special characters can be used and maximum of 70 length characters is allowed.
  • File split size: automatically split files into smaller files. Configurable with kB, MB, or GB sizes. Maximum split size 4 GB.

Time synchronization

The UberLogger features an internal real-time clock (RTC) that tracks time, even during power off (if the battery is installed, which it is by default). You can synchronize the RTC with your local time via the "Configuration" page. This ensures accurate timestamps for recorded data.

Note: Data is saved in Coordinated Universal Time (UTC), which helps merge datasets easily across time zones.

Network & system

Wi-Fi configuration

The UberLogger can operate in two modes:

  1. Hotspot mode: Connect directly to the UberLogger via a device with WiFi. Access the control panel via http://192.168.4.1.
  2. Client + Hotspot mode: Configure the logger to connect to a WiFi network. Access the control panel via the IP address assigned through the DHCP server.

You can configure the WiFi settings in the "Configuration" page under the "Network" tab.

Hotspot security: The device's own access point can be left open (no password) or secured with WPA2/WPA3. When secured, set a password of 8–63 characters. Clients connecting to the hotspot will then need this password.

Network security (client mode): When connecting the logger to an existing WiFi network, choose between an open network or a password-protected one.

Note: When connecting to your access point, only 2.4 GHz Wi-Fi WPA2/WPA3 networks are supported.

Web interface security

The web interface (and all REST/file endpoints) can be protected with HTTP Basic Authentication. Configure this under the Network tab on the Configuration page.

  • No login required: Anyone with network access to the device can use the web interface. This is the default.
  • Password protected: The browser shows a native login dialog when navigating to the device. The username is fixed as admin; set the password yourself.

Note: Basic Auth is sent in clear text over HTTP. Treat the password as a deterrent against casual access on a shared network, not as strong protection.

Firmware update

Firmware updates are performed via the dedicated Firmware Update page in the web interface. The page accepts the three binaries produced by the build system:

  • ota_main.bin — ESP32 main application
  • ota_support.bin — STM32 support chip firmware
  • ota_filesystem.bin — SPIFFS filesystem image (web interface assets)

Select all three files, then start the update. Live progress is shown during upload and flashing. Once flashing completes, the device restarts and the page waits for it to come back online before reporting success.

Note: Disconnect all sensors and signals from the inputs (AIN / NTC and DIO) before updating: signals on the inputs can stop the support chip from being updated. Do not power down the device during an update. Active logging is paused for the duration of the update.

Import / export configuration

The Import/Export Configuration section allows you to save or load the configuration settings of the UberLogger.

Export Configuration: You can download the current configuration settings to a JSON file for backup or to apply to another device later.

Import Configuration: This allows you to load a previously saved JSON configuration file to restore settings or replicate configurations across multiple devices.
